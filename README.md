# 养老看板 · Retirement Dashboard

一个纯前端的**目标导向**养老规划看板：你只需要描述"退休想怎么活"，系统自动倒推出**该攒多少储蓄、每月要存多少钱**。

技术栈：Tailwind CSS（CDN）+ ECharts 5 + html2canvas + KaTeX（公式渲染）。无构建步骤、无后端、无依赖安装。

## 核心模型：倒推（Goal-based）

与传统"手填一个目标、看够不够"不同，本看板把目标与储蓄额全部**由生活方式倒推**：

1. **所需养老储蓄额** $C$ —— 由退休期支出倒推：
   $$C=\frac{-F_T}{(1+r)^{T}},\quad T=\text{预期寿命}-\text{退休年龄}$$
   其中 $F_T$ 为退休期净现金流（养老金收入 − 生活/医疗/护理支出，含通胀与医保报销）累积到预期寿命的终值。
2. **每月需存** $D=A/12$ —— 由 $C$、当前已存、距退休年数按累积口径反解，使增长曲线恰好落到 $C$。
   - **购买力恒定**：每月 $D$（按今天购买力，年年相等）
   - **账面递增**：第 $k$ 年每月 $D(1+\pi)^k$

三段完全闭环：每月存 $D$ → 退休时攒到 $C$ → 支取至预期寿命归零。所有公式在各模块下方以 KaTeX 小字展示。

## 功能模块

| 模块 | 内容 |
|---|---|
| 顶部 KPI | 所需储蓄额、每月需存（购买力/账面）、退休倒计时 |
| 攒钱期 | 年龄/收益率/通胀/已存 参数；累积增长曲线落到所需储蓄额 |
| 花钱期（模拟器） | 生活水平/养老金/医保/医疗通胀/护理/大额医疗/预期寿命 → 余额逐年支取曲线 + 三阶段支出构成 |
| 人口金字塔 | UN WPP 2024 数据（1950–2050 逐年），标记"当年你几岁" |
| 宏观数据 | CPI / 存款利率 / 国内总储蓄率 / M2-GDP |
| 资产配置 | 7 类资产等效利率（演示性模型） |
| 敏感性热力图 | 收益率 × 通胀率 → 每月需存额 |

## 运行方式

因为各模块用 `fetch` 拼接，**必须通过本地服务器打开**（双击 `file://` 无效）：

```bash
cd retirement
python3 -m http.server 8099
# 浏览器访问 http://127.0.0.1:8099
```

## 项目结构

```
retirement/
├── index.html              # 薄壳：header/footer + 模块容器，fetch 拼装各模块
├── app.css                 # 全局样式
├── shared/                 # 共享层（加载顺序固定）
│   ├── data.js             # 权威数据常量 + 默认状态
│   ├── calc.js             # 计算/倒推函数
│   ├── store.js            # 全局 state + 发布订阅
│   ├── theme.js            # ECharts 主题
│   └── dashboard.js        # 模块加载器/注册表
└── modules/                # 每个面板一个独立文件夹（html + css + js）
    ├── kpi/  growth/  lifestyle/  pyramid/  macro/  asset/  heatmap/
```

新增面板：建 `modules/新名/{新名.html,.css,.js}`（js 里 `Dashboard.register(name, {init,update,resize})`），在 `index.html` 加一个 `<div data-module='新名'></div>` 容器即可。

## 数据来源

- **人口**：联合国 UN World Population Prospects 2024（中方案），十年锚点为真实值、中间年份线性插值；2020 与第七次全国人口普查总量交叉核对一致（差异 <1%）
- **储蓄率**：World Bank「国内总储蓄率（占 GDP）」NY.GDS.TOTL.ZS
- **CPI / GDP / 存款利率 / M2**：国家统计局、中国人民银行
- **养老金替代率**：研究估算值（职工约 45%、机关事业约 70%，国际警戒线 55%），非官方年度统计
- **医保报销**：政策范围内住院报销比例（国家医保局）
- **人均预期寿命**：约 78.6 岁（2023，国家卫健委）
