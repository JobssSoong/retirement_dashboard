# 养老看板 · Retirement Dashboard

一个纯前端的**目标导向**夫妻养老规划看板：描述"退休想怎么活"，系统倒推出**该攒多少、每月存多少**。支持子女养育成本测算、乐观/保守双线对照。

技术栈：Tailwind CSS（CDN）+ ECharts 5 + KaTeX（公式渲染）。无构建步骤、无后端、无依赖安装。

## 核心模型：倒推（Goal-based）

不手填"目标金额"——由生活方式倒推：

1. **所需养老储蓄额** $C$：$C=\dfrac{-F_T}{(1+r)^{T}}$，$F_T$=退休净现金流（养老金−支出）累积到预期寿命的终值
2. **每月需存** $D$：由 $C$、当前已存、距退休年数反解，购买力恒定

### 夫妻独立时间线

- 各自退休年龄、预期寿命、养老金（各自领、去世即停）
- 共同储蓄到较晚退休者（过渡期减半），支取到较晚去世者
- 丧偶期生活支出按系数下调（可调），医疗/护理按在世者本人算

### 子女模拟器（可选）

- **养育成本**（育娲报告，数据驱动）：按抚养档次（农村45/城镇68/中产82/一线120万·到22岁）、孩次递减（二孩71%、三孩60%），均摊到0-22岁各年，抬高每月需存
- **子女支持**（假设值）：用户自填，退休期计入收入
- 月存拆解：`养老 X + 养孩 +Y − 子女支持 Z = 总额`

### 乐观/保守双线

在用户收益率基础上自动 +1.5% 跑第二套场景，KPI 和图表同时显示保守/乐观对照。

## 功能模块

| 模块 | 内容 |
|---|---|
| 顶部 KPI | 所需储蓄额、月存（购买力/账面）、退休倒计时（本人+配偶），含乐观对照 |
| 子女模拟器 | 可开关；抚养档次+孩子年龄+子女支持；月存拆解 |
| 规划面板 | 攒钱+花钱参数合并一区（竖线分隔）；终身组合图（余额线+每年应存柱+支出三色堆叠柱）；三阶段支出构成 |
| 人口金字塔 | UN WPP 2024（1950–2090 逐年），标记本人+配偶当年年龄，出生率假设说明 |
| 宏观数据 | CPI/存款利率/储蓄率/M2-GDP + 养老金基金收支 + 房价；2025-2090 预测（虚线） |
| 资产配置 | 7 类资产等效利率（演示性模型） |
| 敏感性热力图 | 收益率 × 通胀率 → 每月需存额（防抖） |
| 附录 | 15 条数据来源与可信度（真实/推测/估算），带链接 |

### 交互细节

- 生活/护理/重大医疗为**连续滑块**（不吸附），按值落区间提示档次
- 每个数据点带**可信度徽标**（🟢真实/🟡推测/🔴估算），hover 详解，点击跳转附录高亮
- 所有金额输入按**当前购买力**，模型按通胀/医疗通胀推算各年账面
- 各退休账面小字标注**年份**（不同年份折算不同）
- 参数自动存 localStorage + URL hash（可分享），支持导出 JSON
- 炭黑+琥珀金主题，KaTeX 渲染公式

## 运行方式

```bash
cd retirement
python3 -m http.server 8099
# 浏览器访问 http://127.0.0.1:8099
```

## 数据来源

- **人口**：UN WPP 2024（1950–2090），十年锚点真实、中间插值
- **储蓄率**：World Bank NY.GDS.TOTL.ZS
- **CPI/GDP/M2/存款利率**：国家统计局、人民银行
- **养老金基金**：人社部统计公报
- **房价**：统计局商品房均价 + 中指院百城均价
- **养育成本**：育娲《中国生育成本报告2024》
- **子女代际支持**：第五次中国城乡老年人生活状况抽样调查
- **养老金替代率/医保报销/预期寿命/护理价**：研究估算/行业值（已在界面标注）
- 所有来源详见网页底部附录
